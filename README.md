# Paintings Calc

Небольшой веб-инструмент, который размещает картины на холсте заданной ширины и подбирает минимально необходимую длину холста. Результат также отображается в виде наглядной схемы.

Каждую картину можно повернуть, а вокруг неё резервируется свободное пространство (отступ). По умолчанию отступ составляет **5 см с каждой стороны**; его можно изменить в веб-интерфейсе.

## Возможности

- Указание ширины холста в сантиметрах.
- Добавление любого количества картин с указанием ширины, высоты и количества.
- Настройка собственного отступа вокруг каждой картины (в сантиметрах с каждой стороны).
- Автоматический подбор ориентации картин для минимизации длины холста.
- Быстрый расчёт: эвристика с полным перебором поворотов для небольших наборов — почти всегда оптимальный результат за доли секунды.
- Отображение необходимой длины холста и визуальной схемы размещения в браузере.

## Требования

Заранее установите:

- [Python](https://www.python.org/downloads/) версии 3.10 или новее.
- [Git](https://git-scm.com/downloads).
- Современный браузер (Chrome, Firefox, Edge, Safari и т. п.).

## Установка

Клонируйте репозиторий:

```bash
git clone https://github.com/ogurec2009/paintings_calc.git
cd paintings_calc
```

Создайте и активируйте виртуальное окружение, если необходимо:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

В Windows (PowerShell):

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
```

Установите зависимости:

```bash
pip install "fastapi[all]"
```

## Запуск

Проект состоит из двух частей: серверной части на FastAPI и статического веб-интерфейса. Для работы нужны обе.

### 1. Запустите серверную часть

Из директории (папки) проекта (с активированным виртуальным окружением, если зависимости устанавливались в него):

```bash
uvicorn main:app --reload --host 127.0.0.1 --port 8000
```

Или
```powershell
python -m uvicorn main:app --reload --host 127.0.0.1 --port 8000
```

### 2. Запустите веб-интерфейс

Откройте `site/index.html` в браузере с помощью Проводника или другого файлового менеджера.

> Пока вы пользуетесь страницей, серверная часть должна работать на порту `8000`, поскольку расчёты отправляются на `http://127.0.0.1:8000/api/pack`.

## Использование

1. Укажите ширину холста в сантиметрах.
2. Задайте отступ вокруг каждой картины в сантиметрах (по умолчанию 5 см). Отступ применяется с каждой стороны, поэтому расстояние между двумя соседними картинами будет в два раза больше.
3. Добавьте картины: ширину и высоту в сантиметрах, а также нужное количество экземпляров.
4. Нажмите **«Рассчитать и визуализировать»**.
5. Посмотрите необходимую длину холста и схему размещения под формой. Пунктирная линия внутри каждого блока обозначает границу самой картины, а цветной блок включает зарезервированный отступ.

## Как работает расчёт

Картины укладываются рядами по ширине холста (shelf packing): для каждой подбирается поворот, минимизирующий высоту ряда. Выполняется несколько проходов с разными порядками сортировки (по убыванию короткой стороны, длинной стороны, площади, а также в исходном порядке ввода) и возвращается лучший результат.

Для наборов **до 12 картин** дополнительно выполняется полный перебор всех 2^n комбинаций поворотов для каждого из порядков — это занимает доли секунды и почти всегда даёт оптимальную длину. Для больших наборов используется только эвристика, и результат может быть немного длиннее оптимального.

```json
{
  "canvas_width": 150,
  "paintings": [[50, 70], [30, 40]],
  "offset": 5
}
```
